# MajorLauncher

Лаунчер Minecraft: Java Edition для Windows, который не мешает игре: быстрый, лёгкий и работает на слабых ПК. Без рекламы, без телеметрии, без своих серверов: всё, что уходит чужим сервисам (перевод описаний модов, ИИ-разбор ошибок), включается только вручную в настройках. Открытый код под лицензией GPL-3.0.

> **Статус:** все этапы до 1.0 сделаны, идёт проверка перед выпуском. Установщик появится в [Releases](https://github.com/Majorzxc/MajorLauncher/releases) — его собирает GitHub Actions прямо из этого кода, дальше лаунчер обновляется сам.

## Возможности

- **Сборки:** любая версия игры с Fabric, Forge или NeoForge; группы, закрепление, архив, корзина, обложки. Снапшоты перед каждым изменением и откат в один клик, перевод сборки на новую версию игры, экспорт и импорт `.mrpack`, импорт из Prism, официального лаунчера, TLauncher, Legacy Launcher, CurseForge и Modrinth App.
- **Запуск:** одна кнопка «Играть» — нужная Java и файлы игры скачиваются и проверяются сами, видно, что делается, запуск можно отменить. «Быстрая игра» в любую версию без сборки. Старые версии (до 1.6) тоже держат всё в своей папке.
- **Моды:** каталог Modrinth с фильтрами — моды, ресурспаки, шейдеры, сборки — с проверкой совместимости и зависимостей до запуска; обновления, закрепление версий, библиотека модов и паков, проверка на известный вредоносный код.
- **Один раз настроил — работает везде:** общие настройки игры, клавиши (есть редактор) и список серверов для всех сборок, в том числе для версий до 1.13.
- **Ошибки:** анализатор объясняет краш человеческим языком и предлагает решение кнопкой; по желанию — ИИ-разбор вашим собственным ключом. «Собрать логи» — архив для сообщения об ошибке без личных данных.
- **«Оптимизировать»:** оптимизаторы, память и видеокарта под ваш ПК, с отчётом и откатом.
- **Серверы:** общий список с состоянием серверов и «Играть на сервере» — лаунчер подберёт сборку и сразу зайдёт.
- **Скины:** библиотека, каталоги Ely.by и MineSkin, 3D-просмотр, плащи.
- **Аккаунты:** Ely.by и офлайн-ники, сколько угодно; ключи входа — в защищённом хранилище Windows.
- **Остальное:** статистика игрового времени, чёрная и белая темы со своими цветами и картинкой фона, мастер первого запуска с обучением, перетаскивание файлов в окно, обновления лаунчера с проверкой подписи.

## Бюджеты

| Что | Бюджет | Замер (этап 3, FX-8300, HDD) |
|---|---|---|
| Память во время игры (окно закрыто) | до 20 МБ | 8 МБ |
| Память с открытым окном | до 150 МБ | 104–110 МБ |
| Открытие окна | до 2 с (SSD), до 4 с (HDD) | 1,2 с до готового экрана |
| Размер установщика | до 15 МБ | 4,5 МБ (этап 10) |

## Устройство

```
core/  — вся логика: версии, загрузки, запуск, моды, сборки, анализ логов. Без интерфейса
cli/   — консольная утилита mlcli поверх core, для тестов и автоматизации
app/   — окно: Tauri 2 + Svelte, только отображение и кнопки
```

Интерфейс ничего не решает сам: что и откуда скачать, что запустить — решает ядро.

## Сборка из исходников

Нужны: Rust (stable), Node.js 20+, MSVC Build Tools (компонент «C++ build tools»), WebView2 (есть в Windows 10/11).

```bash
cd app
npm ci
npm run tauri dev     # окно в режиме разработки
npm run tauri build   # установщик в target/release/bundle/nsis
```

## Выпуски и обновления

Установщик собирает GitHub Actions из кода тега ([`release.yml`](.github/workflows/release.yml)) — любой может сверить, что выпуск собран из открытого кода. Рядом с установщиком в выпуске лежат `update.json` (версия, имя файла, размер, SHA-256), его подпись `update.json.sig` и `SHA256SUMS.txt`. Лаунчер ставит обновление, только если подпись сходится с ключом, вшитым в лаунчер, версия новее текущей, а скачанный файл совпал по размеру и хешу.

Как выпустить версию:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/set-version.ps1 1.0.0   # Cargo.toml, tauri.conf.json, package.json
# необязательно: release-notes/1.0.0.md — «что нового» (иначе GitHub перечислит коммиты)
git commit -am "Версия 1.0.0"
git tag v1.0.0
git push origin main v1.0.0
```

Тег с дефисом (`v1.1.0-beta.1`) — пробная версия: её видят только те, у кого в «Настройки → Обновления» выбран канал «Бета». Подписывает выпуск секрет репозитория `UPDATE_SIGNING_KEY` — закрытый ключ в base64 (создаётся `mlcli release keygen <файл>`, открытый ключ — `PUBLIC_KEY` в `core/src/selfupdate.rs`).

## Консольная утилита mlcli

```bash
cargo build --release -p majorlauncher-cli
```

Утилита появится в `target/release/mlcli.exe`. Все файлы игры она хранит в папке `--data` (по умолчанию `mldata` в текущей папке).

```bash
mlcli versions                                        # последние релизы
mlcli versions --all                                  # вместе со снапшотами, альфами и бетами
mlcli --data D:/MajorLauncherData install 1.21.1      # скачать версию целиком
mlcli --data D:/MajorLauncherData launch 1.21.1 --nick Steve --memory 4096
mlcli --data D:/MajorLauncherData verify 1.21.1       # пересчитать хеши и починить повреждённое
mlcli --data D:/MajorLauncherData mods my-build        # моды сборки: что за мод, обновления, предупреждения
mlcli --data D:/MajorLauncherData modpack sop          # сборка из каталога Modrinth (id или slug)
mlcli --data D:/MajorLauncherData mrpack pack.mrpack   # сборка из файла .mrpack
mlcli --data D:/MajorLauncherData servers              # общий список серверов с опросом каждого
mlcli servers ping hypixel.net 2b2t.org                # опросить адреса не из списка
mlcli servers add "Мой сервер" play.example.org        # ещё: remove, move, edit; --build — свой список сборки
mlcli self-update [--beta]                             # есть ли новая версия лаунчера (с проверкой подписи)
mlcli release sign --key <ключ> <установщик>           # update.json и подпись для выпуска
```

Вместо номера версии можно написать `release` или `snapshot` — последняя версия.

### Аккаунты

```bash
mlcli accounts                          # список; звёздочка — аккаунт по умолчанию
mlcli accounts add-offline Steve        # офлайн-ник
mlcli accounts add-ely mylogin          # вход через Ely.by, пароль спросит скрыто
mlcli accounts default ely:Steve        # аккаунт по умолчанию
mlcli accounts remove offline:Steve
mlcli launch 1.21.1                     # с аккаунтом по умолчанию
mlcli launch 1.21.1 --account Alex      # с другим аккаунтом
mlcli launch 1.21.1 --nick Guest        # разовый офлайн-ник без сохранения
```

- Пароль Ely.by не сохраняется. Лаунчер хранит только выданный токен — в «Диспетчере учётных данных» Windows, а не в файлах. Если на аккаунте включена двухфакторная защита, `mlcli` спросит код.
- Перед запуском токен проверяется и при необходимости обновляется. Если интернета нет, одиночная игра всё равно запустится.
- Для Ely.by к игре подключается [authlib-injector](https://github.com/yushijinhun/authlib-injector) — через него работают скины и вход на серверы Ely.by. Версия закреплена вместе с хешем.
- Офлайн-UUID вычисляется так же, как на сервере Minecraft, поэтому вещи и прогресс на офлайн-серверах привязываются к нику так же, как в других лаунчерах.

Что делает `mlcli`:

- скачивает нужную Java от Mojang (своя Java на компьютере не нужна и не трогается);
- качает параллельно, после обрыва продолжает с места остановки;
- проверяет хеш каждого файла; повреждённый или подменённый файл перекачивается;
- если официальный сервер недоступен, берёт ассеты и библиотеки с запасного зеркала — с той же проверкой хеша;
- общие файлы (библиотеки, ассеты, Java) хранятся один раз на все версии;
- при запуске не пересчитывает хеши заново: проверяет только файлы, у которых изменились размер или дата. Подготовка к запуску — около 0,1–0,2 с.

Проверено на версиях 26.3 (Java 25), 1.21.1 (Java 21), 1.12.2 и 1.5.2 (Java 8).

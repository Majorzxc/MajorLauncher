# MajorLauncher

Лаунчер Minecraft: Java Edition для Windows, который не мешает игре: быстрый, лёгкий и работает на слабых ПК. Без рекламы, без телеметрии, без своих серверов. Открытый код под лицензией GPL-3.0.

> **Статус:** ранняя разработка, этап 0 — каркас проекта. Играть через него пока нельзя.

## Что будет в 1.0

- запуск любых версий игры, нужная Java скачивается сама;
- вход через Ely.by и офлайн-ники, сколько угодно аккаунтов;
- Fabric, Forge, NeoForge;
- каталог Modrinth: моды, ресурспаки, шейдеры, сборки — с проверкой совместимости и зависимостей до запуска;
- сборки с переводом на новую версию игры, снапшотами и откатом в один клик;
- анализатор ошибок, который объясняет краш человеческим языком и предлагает решение, плюс ИИ-разбор вашим собственным ключом;
- кнопка «Оптимизировать», которая реально что-то делает под ваше железо;
- скины с 3D-просмотром, статистика игрового времени.

## Бюджеты

| Что | Бюджет |
|---|---|
| Память во время игры (окно закрыто) | до 20 МБ |
| Память с открытым окном | до 150 МБ |
| Открытие окна | до 2 с (SSD), до 4 с (HDD) |
| Размер установщика | до 15 МБ |

## Устройство

```
core/  — вся логика: версии, загрузки, запуск, моды, сборки, анализ логов. Без интерфейса
cli/   — консольная утилита mlcli поверх core, для тестов и автоматизации
app/   — окно: Tauri 2 + Svelte, только отображение и кнопки
```

Интерфейс ничего не решает сам: что и откуда скачать, что запустить — решает ядро.

## Сборка из исходников

Нужны: Rust (stable), Node.js 20+, MSVC Build Tools (компонент «C++ build tools»), WebView2 (есть в Windows 10/11).

```bash
cd app
npm ci
npm run tauri dev     # окно в режиме разработки
npm run tauri build   # установщик в target/release/bundle/nsis
```

Консольная утилита:

```bash
cargo run -p majorlauncher-cli
```

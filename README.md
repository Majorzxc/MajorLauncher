# MajorLauncher

Лаунчер Minecraft: Java Edition для Windows, который не мешает игре: быстрый, лёгкий и работает на слабых ПК. Без рекламы, без телеметрии, без своих серверов. Открытый код под лицензией GPL-3.0.

> **Статус:** ранняя разработка. Этап 1 готов: консольная утилита `mlcli` скачивает и запускает любую ванильную версию с офлайн-ником. Окна с кнопкой «Играть» пока нет — это этап 3.

## Что будет в 1.0

- запуск любых версий игры, нужная Java скачивается сама;
- вход через Ely.by и офлайн-ники, сколько угодно аккаунтов;
- Fabric, Forge, NeoForge;
- каталог Modrinth: моды, ресурспаки, шейдеры, сборки — с проверкой совместимости и зависимостей до запуска;
- сборки с переводом на новую версию игры, снапшотами и откатом в один клик;
- анализатор ошибок, который объясняет краш человеческим языком и предлагает решение, плюс ИИ-разбор вашим собственным ключом;
- кнопка «Оптимизировать», которая реально что-то делает под ваше железо;
- скины с 3D-просмотром, статистика игрового времени.

## Устройство

```
core/  — вся логика: версии, загрузки, запуск, моды, сборки, анализ логов. Без интерфейса
cli/   — консольная утилита mlcli поверх core, для тестов и автоматизации
app/   — окно: Tauri 2 + Svelte, только отображение и кнопки
```

Интерфейс ничего не решает сам: что и откуда скачать, что запустить — решает ядро.

## Сборка из исходников

Нужны: Rust (stable), Node.js 20+, MSVC Build Tools (компонент «C++ build tools»), WebView2 (есть в Windows 10/11).

```bash
cd app
npm ci
npm run tauri dev     # окно в режиме разработки
npm run tauri build   # установщик в target/release/bundle/nsis
```

## Консольная утилита mlcli

```bash
cargo build --release -p majorlauncher-cli
```

Утилита появится в `target/release/mlcli.exe`. Все файлы игры она хранит в папке `--data` (по умолчанию `mldata` в текущей папке).

```bash
mlcli versions                                        # последние релизы
mlcli versions --all                                  # вместе со снапшотами, альфами и бетами
mlcli --data D:/MajorLauncherData install 1.21.1      # скачать версию целиком
mlcli --data D:/MajorLauncherData launch 1.21.1 --nick Steve --memory 4096
mlcli --data D:/MajorLauncherData verify 1.21.1       # пересчитать хеши и починить повреждённое
```

Вместо номера версии можно написать `release` или `snapshot` — последняя версия.

Что делает `mlcli`:

- скачивает нужную Java от Mojang (своя Java на компьютере не нужна и не трогается);
- качает параллельно, после обрыва продолжает с места остановки;
- проверяет хеш каждого файла; повреждённый или подменённый файл перекачивается;
- если официальный сервер недоступен, берёт ассеты и библиотеки с запасного зеркала — с той же проверкой хеша;
- общие файлы (библиотеки, ассеты, Java) хранятся один раз на все версии;
- при запуске не пересчитывает хеши заново: проверяет только файлы, у которых изменились размер или дата. Подготовка к запуску — около 0,1–0,2 с.

Проверено на версиях 26.3 (Java 25), 1.21.1 (Java 21), 1.12.2 и 1.5.2 (Java 8).

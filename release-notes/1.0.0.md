Первый выпуск MajorLauncher — лаунчера Minecraft: Java Edition для Windows 10/11. Без рекламы и телеметрии, с открытым кодом (GPL-3.0).

## Что умеет

- **Сборки:** любая версия игры с Fabric, Forge или NeoForge; группы, закрепление, архив, корзина, снапшоты с откатом в один клик, перевод сборки на новую версию игры, экспорт и импорт `.mrpack`, импорт из Prism, официального лаунчера, TLauncher, Legacy Launcher, CurseForge и Modrinth App.
- **Моды:** каталог Modrinth с фильтрами, зависимости и предупреждения о несовместимости, обновления, библиотека модов, ресурспаков и шейдеров, проверка на известный вредоносный код.
- **Запуск:** одна кнопка «Играть» — лаунчер сам скачает и проверит файлы и Java; «Быстрая игра» в любую версию; общие настройки игры и клавиши для всех сборок; «Оптимизировать» под ваш ПК.
- **Ошибки:** разбор падений игры с понятным объяснением и кнопками решения, по желанию — ИИ-разбор вашим ключом.
- **Скины:** библиотека, каталоги Ely.by и MineSkin, 3D-просмотр.
- **Серверы:** общий список для всех сборок с состоянием серверов, «Играть на сервере» с подбором подходящей сборки.
- **Аккаунты:** Ely.by и офлайн-ники. Ключи входа — в защищённом хранилище Windows.

## Установка

Скачайте `MajorLauncher_1.0.0_x64-setup.exe` ниже. Установщик не требует прав администратора. Windows может показать «Неизвестный издатель»: у проекта нет платного сертификата Microsoft. Проверить, что файл собран здесь, из этого кода, можно по `SHA256SUMS.txt`.

Дальше лаунчер обновляется сам: каждое обновление подписано, без верной подписи он его не поставит.
